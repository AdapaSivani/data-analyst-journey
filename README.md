# My Data Analyst Journey

Hi! Welcome to my Data Analyst Journey repository. 

I'm Shivani, a B.Tech Data Science student who is passionate about learning how to work with data and solve real-world problems through analysis.

I created this repository to document my learning journey from the very beginning. Instead of only uploading final projects, I want to share my progress, practice files, notes, and everything I learn along the way. I believe that every small step contributes to becoming a better data analyst.
